# OrderFlow CRM

Информационная система управления клиентами и заказами малого бизнеса,
реализованная в виде Telegram-бота.

## Возможности

- Регистрация пользователей и личный кабинет
- CRUD клиентов: добавление, поиск, список, карточка клиента
- CRUD заказов: создание, список, изменение статуса заказа
- Статистика по клиентам, заказам и выручке
- Экспорт отчёта в PDF (с поддержкой кириллицы)
- Настройки профиля (название бизнеса)

## Стек технологий

- Python 3.11+
- aiogram 3 (асинхронный фреймворк для Telegram Bot API)
- SQLAlchemy 2 (async ORM)
- SQLite (aiosqlite)
- python-dotenv
- reportlab (генерация PDF)

## Установка и запуск

1. Создайте виртуальное окружение и установите зависимости:

   ```bash
   python -m venv venv
   source venv/bin/activate      # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

2. Получите токен бота у [@BotFather](https://t.me/BotFather).

3. Скопируйте `.env.example` в `.env` и укажите токен:

   ```bash
   cp .env.example .env
   ```

4. Запустите бота:

   ```bash
   python bot.py
   ```

При первом запуске автоматически создаётся файл базы данных `database.db`
со всеми необходимыми таблицами.

## Архитектура

Проект построен по слоистой архитектуре:

- **handlers/** — принимают сообщения/колбэки Telegram, управляют диалогом (FSM)
- **services/** — бизнес-логика и запросы к базе данных (SQLAlchemy)
- **keyboards/** — построение клавиатур (reply и inline)
- **models.py** — описание схемы данных
- **utils/** — вспомогательные функции (валидация, форматирование, состояния)

Каждый пользователь Telegram работает в изолированном пространстве:
видит только своих клиентов и заказы (многопользовательский режим,
подходит для нескольких владельцев малого бизнеса одновременно).

## Возможные доработки

- Пагинация для длинных списков клиентов/заказов
- Роли и права доступа (например, сотрудник vs владелец)
- Уведомления о смене статуса заказа
- Docker-контейнеризация для развёртывания
